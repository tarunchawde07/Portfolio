# Tarun Chavde — Embedded Hardware Engineer Portfolio

A static, responsive portfolio website. It uses plain HTML and CSS, with no build tools or external JavaScript dependencies.

## Preview locally

Open `index.html` in a web browser.

## Publish for free with GitHub Pages

1. Sign in to GitHub and create a **public** repository, for example `tarun-portfolio`.
2. Upload `index.html` to the repository root (the top level). You may also upload this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and use the URL shown in Settings → Pages. It is usually `https://YOUR-USERNAME.github.io/tarun-portfolio/`.

GitHub's interface and publication time may vary. No paid domain is required.
